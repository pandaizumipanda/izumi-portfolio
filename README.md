# IZUMI FUKUYAMA — Portfolio / Speaking

福山いずみの講演・ワークショップと制作実績を紹介する静的サイト。
白・黒・グレーを基調とし、作品画像の色は原作品のまま掲載しています。

## 構成

- `index.html` — 講演を中心にしたトップ、制作実績、プロフィール、問い合わせ
- `event.html` — 講演テーマ例、考え方、依頼の流れ、FAQ、展示活動
- `works.html` — 10件の制作、カテゴリー絞り込み、詳細ダイアログ
- `about.html` — プロフィールと活動分野
- `contact.html` — 相談内容からメールを作成するフォーム、直接メールリンク
- `privacy.html` — プライバシーポリシー

既存URLと作品の `#works-01` などのリンクは維持しています。

## 文章の編集（ここから始める）

**表示文章は `編集用/サイトの文章.txt` の1ファイルにまとめています。**
各項目に「使用箇所」を記載しています。「本文：」から「【ここまで】」までの中身を
書き換えて保存してください。見出し・本文・ボタン・フォーム案内・検索/SNS用の文章も編集できます。
同じ文章を複数ページで使う箇所はまとめて変更されます。

保存後は `編集用/文章を反映.command` をダブルクリックし、ブラウザを再読み込みします。
ターミナルなら `python3 tools/build_site.py` でも同じです。公開には別途GitHubへの反映が必要です。

- 文言ID・区切り・使用箇所の行は変更しないでください。
- HTMLタグは不要です。本文の改行は表示にも反映されます。
- 文中の `{count}` / `{name}` などは動的な値です。残してください。
- `content.txt` は作品の追加・分類・画像名・メール送信先・リンク先などの構造と元データです。
  表示文の修正には編集用ファイルを優先します。
- レイアウトは `tools/build_site.py`、文章の適用処理は `tools/site_copy.py`、
  デザインは `assets/css/style.css`、動作は `assets/js/main.js` です。
- 生成されたHTMLを直接編集すると次のビルドで上書きされます。

```sh
python3 tools/build_site.py
python3 tools/dev_server.py
```

ブラウザで `http://localhost:5173` を開きます。追加ライブラリは不要です。

## 講演の写真を差し替える

現在、添付された実際の講座写真を `images/speaking-01.jpg` と `images/speaking-02.jpg` に保存しています。
1枚目はトップと講演ページ、2枚目は講演ページで大きく掲載します。

1. 差し替える写真を `images/` に配置します。
2. `content.txt` の `[speaking]` の `photo:` を次のように設定します。

```text
photo: speaking-01.jpg
photo_alt: バイブコーディングの講演の様子
photo_secondary: speaking-02.jpg
photo_secondary_alt: 参加者がパソコンを使いながら取り組む講座の様子
```

3. `python3 tools/build_site.py` を実行します。

写真にはフレームや背景・余白の装飾を付けず、元の縦横比で表示します。
写真が未指定・存在しない場合は図案を表示し、空の画像枠は出しません。

講演テーマは `[talk]`、考え方は `[approach]`、依頼の流れは `[step]`、
質問は `[faq]` で編集します。テーマ例は開催実績とは区別しています。
確認できていない開催日・人数・主催者・推薦コメントは掲載していません。
旧イベントの未記入値は元データに残し、公開ページには出していません。

## 制作画像

原本の `images/*.png` は保存し、表示には `images/web/*.jpg` を優先します。
原本を差し替えた場合、macOSで以下を実行してください。

```sh
python3 tools/prepare_images.py
python3 tools/build_site.py
```

`prepare_images.py` はmacOS標準の `sips` を使います。長辺1600px以下・JPEG品質82で
原本を変更せずに別ファイルを出力します。別OSでは `images/web/` の同名JPEGを
直接差し替えるか、該当JPEGを削除して原本PNGを使用してください。

`works-06` と `works-07` は現在 `image_pending: true` により、仮画像の代わりに
作品名のタイポグラフィを表示します。画像を用意したらこの行を削除してください。

## お問い合わせ

送信先は `[site]` の `email:` に指定されています。
`form_action:` が空の場合、フォームの内容を訪問者のメールアプリへ引き継ぎます。
Webページ上で直接送信はされません。送信はメールアプリ側で行います。
メールアプリが使えない場合のため、直接コピーできるメールアドレスも掲載しています。

フォームサービスを導入する際は `form_action:` に受信先URLを指定します。
送信項目は `name / company / email / type / message` です。
外部サービス側の受信設定・動作検証は別途必要です。

## 公開

公開URL: https://pandaizumipanda.github.io/izumi-portfolio/

GitHub Pagesは `main` ブランチ直下のHTMLを配信します。
**PythonによるHTML生成はGitHub側では自動実行されません。**
ローカルでビルドし、HTML・CSS・JS・必要画像をコミットしてGitHubにpushすると公開が更新されます。
`content.txt` だけを変更してpushしても、表示は更新されません。

## 動作の配慮

- 外部フォントやJavaScriptライブラリへの依存なし
- スマートフォン用メニュー、キーボード操作、フォーカス表示
- OSの「視差効果を減らす」設定ではアニメーション停止
- JavaScriptなしでもナビゲーション・作品説明・直接メールリンクを表示
- 制作の詳細を直接リンク可能。ダイアログはEscape・閉じるボタン・背景で閉じます
- 画像は遅延読み込み、アセットURLには内容ハッシュを付与

旧デザイン用の `gen_placeholders.py`、`shrink_deco.py` と背景装飾原本は残していますが、
新しいサイトのビルドには使用しません。

## アニメーション

`assets/js/main.js` の後半でスクロール時の動きを制御します。大きな英字見出しは
浮き上がり・回転・ぼかし、見出しは大きめの移動、本文は控えめなフェード、写真は
ゆっくりしたフェードと拡大です。表示された要素は一度だけアニメーションします。
サイト内のページ移動は約230msのフェードアウト後に遷移します。
リンクの別タブ操作、作品ダイアログ、ページ内アンカー、外部リンクは通常通り動作します。
OSの「視差効果を減らす」設定に追従して停止します。JavaScript無効でも内容は表示されます。

ご当地ほりにしの原本は拡張子がPNGですが、中身はJPEGです。以前の変換で黒画像が生成されたため、
`prepare_images.py` ではこの原本を再圧縮せず `images/web/works-01.jpg` にコピーします。
